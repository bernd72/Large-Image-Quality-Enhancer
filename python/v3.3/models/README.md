# Local AI models / Lokale KI-Modelle

This directory intentionally contains **no model weights**. / In diesem Ordner sind absichtlich **keine Modellgewichte** enthalten.

To run the Python application, obtain the appropriate models legally and put them here:

- `DPRNet_1024.tflite` (or supported alternative `DPRNet_512.tflite`)
- `scunet_color_real_psnr.onnx`
- `scunet_color_real_psnr.onnx.data`

Keep ONNX and ONNX external-data files together, with these exact names. Follow all upstream license and attribution requirements. See [third-party notices](../../../THIRD_PARTY_NOTICES.md).

**Deutsch:** Benötigte Modelldateien eigenständig und rechtmäßig beschaffen und hier ablegen. Die Rechte an den Gewichten und Konvertierungen sind noch nicht abschließend geprüft; bitte keine fremden Modellgewichte ungeprüft in dieses Repository hochladen.
